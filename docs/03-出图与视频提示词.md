# 第 3 步 · Codex 出图 + 豆包视频提示词

## 交付规则

- **图片**：Codex 生成，横版 16:9，最好是 1920×1080 或更大（比如 2560×1440，方便后期推镜头）。
- **图上不要有任何文字、水印、字幕**，所有文字都在 Remotion 里加。
- **文件名**严格按下面的编号命名，放进 `public/images/`。
- **视频**：豆包（Seedance）图生视频，用对应的图片做首帧，16:9、1080p、5 秒，**关掉声音或者生成后静音**，所有声音在后期统一处理。放进 `public/video/`。
- 做好以后推到 `claude/ecstatic-shannon-13pl2y` 分支，或者直接在对话里发给我。
