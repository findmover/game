## 配音

- 脚本：`scripts/tts_seed_audio.py`，读取 `docs/02-旁白稿.txt`，每个镜头生成一个 `public/audio/vo/Sxx.mp3`，并把实测时长写入 `durations.json`，第 4 步用它来对齐画面。
- 音色：默认用豆包 TTS 2.0 的 `zh_male_m191_uranus_bigtts`（云舟 2.0，低沉、有氛围感），同时在提示词里写明"中年男性、低沉略沙哑、克制悬疑"。每个镜头都传同一个音色 ID，保证 19 句话是同一个声音。不喜欢可以用环境变量 `VOICE_SPEAKER` 换成别的音色。
- 安静处理：S08 和 S16 的提示词会额外要求"压低声音，几乎是低语"。
- 网络放开后的流程：先跑 `--shots S00,S01` 试听，确认音色以后再生成全部镜头。

## 需要你做的事

1. **放开网络 + 配置密钥**（配音必需）
   - 在云端环境设置里（会话标题栏的环境菜单 → Edit）：
     - Network access 的允许域名里加上 `openspeech.bytedance.com`；
     - 添加环境变量 `VOLC_TTS_API_KEY`（控制台里的 API Key，对应示例 curl 里的 `X-Api-Key`）。如果你只有 App ID 和 Access Token，就填 `VOLC_TTS_APP_ID` 和 `VOLC_TTS_ACCESS_TOKEN`。Secret Key 用不到。
   - 改完可能要新开一个会话才生效。所有进度都已经推送到分支，新会话可以直接接着做。
   - 你在聊天里贴过 Access Token 和 Secret Key，建议项目结束后到控制台重置一下。
2. **用 Codex 出 14 张图**：按 [03-出图与视频提示词.md](03-出图与视频提示词.md) 生成，命名后放进 `public/images/`。
3. **用豆包出 4 段视频**：图出好之后，用对应图片做首帧（V09 用首尾帧），放进 `public/video/`。
4. **音乐和音效**，二选一：
   - 放开网络后用 seed-audio 生成（同一个接口，按上面的清单写提示词），或者
   - 你按搜索词从 Pixabay 下载，放进对应目录。
