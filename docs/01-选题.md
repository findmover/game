# 第 1 步 · 选题：三人决斗（Truel）

## 定位

| 项目 | 决定 |
|---|---|
| 主题 | 三人决斗：枪法最差的人，活下来的概率最高 |
| 时长 | 约 90 秒 |
| 平台 / 比例 | B 站 / YouTube 横屏 16:9，1920×1080 |
| 调性 | 悬疑电影感：暗色调、低沉旁白、节奏紧 |
| 一句话钩子 | "三个枪手对决，枪法最差的那个，活下来的概率最高。" |

## 为什么选它

- **反直觉**：一句话就能制造好奇心，适合前 3 秒留人。
- **有故事**：三个角色、一场对峙、一次反转，天然是三幕结构。
- **数学干净**：结论可以精确算出来，不靠模糊的"大概"。
- **画面强**：西部荒野、对峙、慢镜头子弹，跟悬疑电影感很搭。

## 核心设定（经典版本）

| 角色 | 命中率 | 定位 |
|---|---|---|
| A · 菜鸟 | 1/3 | 最弱，最先开枪 |
| B · 快枪手 | 2/3 | 中等 |
| C · 神枪手 | 100% | 最强，最后开枪 |

规则：从最弱的开始轮流开一枪，直到只剩一人。每个人都绝对理性，B 和 C 都会优先打对自己威胁最大的对手。

## 关键数字（已验证）

由 `scripts/truel_odds.py` 精确计算，20 万次蒙特卡洛模拟结果一致：

| A 的第一枪 | A 生存率 | B 生存率 | C 生存率 |
|---|---|---|---|
| 瞄准 C（直觉做法） | 31.2% | 54.0% | 14.8% |
| **朝天开枪（最优）** | **39.7%** | 38.1% | 22.2% |

推理链（用于后面的文案和动画）：

1. A 朝天开枪，谁也不得罪。
2. B 必须打 C：C 是唯一能一枪带走他的人。
3. B 打中 C（2/3）→ A 先手对 B；B 没打中（1/3）→ C 一枪带走 B → A 先手对 C。
4. 不管哪种情况，A 都是**最后一轮对决里先开枪的那个人**。
5. 如果 A 一开始就打中了 C，反而把自己送进了"B 先开枪"的对决，生存率只有 1/7。

## 故事骨架（只是结构，正式文案在第 2 步）

| 时间 | 段落 | 要传达的 |
|---|---|---|
| 0–8s | 钩子 | 荒野对峙，抛出反常识结论 |
| 8–25s | 设定 | 介绍三人和规则 |
| 25–50s | 直觉陷阱 | "当然该打最强的"，结果 A 只有 31% |
| 50–75s | 反转 | A 朝天开枪，强者互相残杀，A 升到 39.7% |
| 75–90s | 升华 | 太强会让你成为所有人的靶子；弱者的智慧在于"不出手" |

- 字体：标题用衬线体，数据用等宽体
